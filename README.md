# 以隱藏馬可夫模型分析 DNA 序列

成大資工畢業專題，使用 Hidden Markov Model（HMM）分析 DNA 序列，實作 Viterbi、Forward-Backward 與 Baum-Welch 等演算法，並探索 GC-rich region 與 Alu sequence 的辨識。

## 內容

- `src/HMM_Project/`：C 語言版本與不同開發階段
- `src/Python_version/`：Python 實作與小型測試資料
- `src/web/`：簡易網頁介面
- `project-report.pdf`、`project-summary.pdf`：專題報告與摘要

此專題為團隊作品，指導教授為賀保羅教授，成員為謝承佑、曾暐翔。大型染色體資料、虛擬環境與編譯產物未納入 repository。

# Hidden Markov Models for DNA Sequence Analysis

An NCKU Computer Science graduation project that applies Hidden Markov Models to DNA sequence analysis. It includes C and Python implementations of Viterbi, Forward-Backward, and Baum-Welch related workflows, plus a small web interface.

This is a team project advised by Professor Paul Ho and completed by Cheng-Yu Hsieh and Wei-Hsiang Tseng. Large genomic datasets, virtual environments, and build artifacts are intentionally excluded.
